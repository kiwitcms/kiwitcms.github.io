Kiwi TCMS Enterprise 16.5.1
###########################

:headline: improved checks for download requests
:date: 2026-09-20 12:50
:comments: false
:tags: releases


Dear testers, we're happy to announce Kiwi TCMS Enterprise version 16.5.1-mt!

**IMPORTANT:**

This is a minor version release which introduces improved checks for requests to `/uploads/`.


Changes since Kiwi TCMS Enterprise v16.5-mt
-------------------------------------------

- Based on Kiwi TCMS v16.5
- Improve checks for requests to `/uploads/`
- Multiple fixes for issues reported by ShellCheck
- Update sentry-sdk from 2.68.1 to 2.69.2
