Feature spotlight: TestPlan multi-clone & deep-clone

available in Kiwi TCMS v16.6

Posted by Kiwi TCMS Team on Mon 12 October 2026 under features

Cloning Test Plans just got an upgrade in Kiwi TCMS v16.6! Whether you want to duplicate a single plan, a whole handful of them, or an entire nested tree, the new cloning workflow keeps your clicks to a minimum.

Here are the 3 changes we shipped:

1. Clone names now carry the original ID

When you clone a Test Plan the suggested name now includes the original ID, so the lineage of every copy is obvious at a glance:

The Clone of TP-117: prefix is highlighted above. Rename it if you like - but the default now tells you exactly where the copy came from! This feature is intended for the human behind the computer! Feel free to change the new name to whatever fits best in your case.

2. Multi-clone from Search Test Plans page

Need to duplicate a batch? The Search Test Plans page now displays a checkbox column on the lefthand side and the cloning button has joined the buttons row in table header:

Selection is explicit - you tick exactly the records you want - and the clone page displays all of them at the same time. Name, Product, Version, etc are individually adjustable per row:

This functionality was built on top of contributions from Oskar Hurst, U.S. Army Corps of Engineers. Thank you Oskar!

3. Deep clone an entire Test Plan tree

Parent/child relationships can now be preserved when cloning! The cogs menu now offers the Deep clone item which will clone the entire relationship structure starting at the current Test Plan:

The clone page then lays out the whole tree. Each clone keeps its ID-derived name and you get visual level indicators so the hierarchy stays readable while you review it:

When deep cloning, the on/off button used to adjust the parent of individual Test Plans is disabled. The structure is cloned as-is on purpose, so there is nothing to re-parent while the tree is being copied!

Happy Testing!
