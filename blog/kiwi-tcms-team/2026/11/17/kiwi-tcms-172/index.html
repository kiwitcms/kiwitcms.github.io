Kiwi TCMS 17.2

security related updates, new test case template, API changes

Posted by Kiwi TCMS Team on Tue 17 November 2026 under releases

Dear testers, we're happy to announce Kiwi TCMS version 17.2!

IMPORTANT:

This is a minor version release which includes security related updates, new test case template, API changes and internal refactoring.

You can explore everything at https://public.tenant.kiwitcms.org!

---

Public container image (x86_64):

pub.kiwitcms.eu/kiwitcms/kiwitcms   latest  6174939e43cb   1.26GB

IMPORTANT: version tagged and multi-arch container images are available only to subscribers!

Changes since Kiwi TCMS 17.1

Security

  • Require API requests with``<field>__email`` to have auth.view_user permission. Fixes GHSA-c2f9-jhxh-pm22
  • Update django-modern-rpc from 2.1.0 to 2.2.0
  • Update mysqlclient from 2.3.0 to 2.3.1

Improvements

  • Update psycopg from 3.3.8 to 3.3.9
  • Add Context, Intent, Guardrails, Execution template for Test Cases (Vivek Krishna Choppa, AWS). Closes Issue #4724

Bug fixes

  • Preserve parent of root-level TestPlan during deep-clone. Fixes Issue #4687

Database

  • Introduce new migration testcases.0026_add_cige_template

API

  • Treat empty query argument to *.remove* API methods as invalid request to prevent a malformed call from accidentally deleting all records (Anton Degtyarev)

Refactoring and testing

  • Convert API errors to RPCException for compatibility with newer django-modern-rpc
  • Pass request.user to KiwiTCMSHandlerMixin.inspect_rpc_args()

Changes since Kiwi TCMS Enterprise v17.0-mt

  • Based on Kiwi TCMS v17.2
  • Update certbot from 5.9.0 to 5.10.0
  • Update kiwitcms-tenants from 4.10.4 to 4.12.0
  • Update sentry-sdk from 2.74.0 to 2.75.0
  • Update social-auth-app-django from 7.2.0 to 8.1.0. WARNING: users should clear cookies if OAuth login session fails
  • Add title attribute to social auth login icons
  • Align MCP tool error handling with django-modern-rpc 2.2
  • Pass request.user to KiwiTCMSHandlerMixin.inspect_rpc_args()
